- [ ] กด "ถ่ายรูป" ไมล์ออก/ไมล์กลับ → เห็นรูปตัวอย่าง + ถ่ายใหม่ได้
- [ ] ไม่มีปุ่มเลือกไฟล์จากเครื่อง
- [ ] ไม่ถ่ายรูปข้างใดข้างหนึ่ง → ปิดงานไม่ได้ มีข้อความ
- [ ] ปฏิเสธสิทธิ์กล้อง / เปิดบน desktop ไม่มีกล้อง → ขึ้นข้อความให้ใช้มือถือ, ปุ่มถ่ายกดไม่ได้
- [ ] ปิดงานสำเร็จ → หน้าคำขอแสดงรูปไมล์ทั้งสอง + "ระบบรับรูปเมื่อ …" (ผู้ขอ/ผู้จัดรถ/พขร. เห็น, เพื่อนร่วม org คนอื่นไม่เห็น)

### T13 ยืนยันเวลาปิดงาน
- [ ] หลัง พขร. ปิดงาน ผู้ขอเห็นเวลาเริ่ม/ปิดงาน + ปุ่ม "ถูกต้อง" / "ไม่ถูกต้อง"
- [ ] กด "ถูกต้อง" → สถานะยืนยันแล้ว, ปุ่มหาย
- [ ] คำขออีกใบ กด "ไม่ถูกต้อง" + เวลาจริง + หมายเหตุ → ผู้จัดรถได้อีเมล, หน้าแสดงเวลาที่แจ้ง
- [ ] "ไม่ถูกต้อง" โดยไม่ใส่เวลา → ขึ้นข้อความเตือน
- [ ] งานที่ปิดเกิน 3 วันไม่มีใครตอบ (แก้ `completed_at` ใน DB) → แสดง "ยืนยันอัตโนมัติ", ตอบไม่ได้แล้ว

### T14 ลายเซ็น
- [ ] หน้าโปรไฟล์มีการ์ด "ลายเซ็น": อัปโหลด PNG/JPG → แสดงลายเซ็นปัจจุบัน
- [ ] วาดบนช่องวาดด้วยเมาส์ และด้วยนิ้วบนมือถือ → ปุ่มล้าง → วาดใหม่ → บันทึก
- [ ] อัปโหลดไฟล์ไม่ใช่รูป / เกิน 2 MB → ถูกปฏิเสธ
- [ ] ลบลายเซ็น → หายไป
- [ ] ผู้อนุมัติที่มีลายเซ็นกดอนุมัติ → หน้าคำขอแสดงลายเซ็นในขั้นนั้น

### T16 เบอร์โทรเร่งด่วน
- [ ] admin ตั้งเบอร์ที่หน้า "ตั้งค่า"
- [ ] ผู้ขอยื่นคำขอที่เหลือ < 3 วันทำการ → popup มีเบอร์ + กดแล้วโทรออก (บนมือถือ)
- [ ] ลบเบอร์ → popup ไม่มีบรรทัดเบอร์

### D1 พิมพ์ใบขอใช้รถ (PDF)
- [ ] ผู้ขอ/ผู้อนุมัติ/ผู้จัดรถ เห็นปุ่ม "พิมพ์ใบขอใช้รถ (PDF)"; คนนอกไม่เห็น เข้า URL ตรงไม่ได้
- [ ] ทั้ง 4 ประเภท: เปิด PDF → ข้อความอยู่บนเส้นประตรงช่อง ไม่ทับตัวพิมพ์ ข้อความยาวย่อ/ตัดพอดีช่อง
- [ ] ขั้นที่อนุมัติแล้ว: ชื่อ + ตำแหน่ง + วันที่ + รูปลายเซ็น อยู่ในช่องลงชื่อของขั้นนั้น; ขั้นที่ยังไม่ถึงว่าง
- [ ] ผู้ขอมีลายเซ็น → อยู่บนบรรทัด "ผู้ขอใช้รถ"
- [ ] งานเสร็จแล้ว → บรรทัด เลข ก.ม. ออก/กลับ/รวมระยะทาง/เป็นเงิน มีค่า
- [ ] พิมพ์ลงกระดาษ A4 จริง 1 แผ่น → ตรวจขอบและตำแหน่ง

### F1 เอกสารเบิก (PDF)
- [ ] คำขอในประเทศที่ "เสร็จสิ้น": หัวหน้าขึ้นไปเห็นปุ่ม "เอกสารเบิกค่าเดินทาง" และ "เอกสารเบิกค่าเบี้ยเลี้ยง"; สวัสดิการ/ต่างประเทศเห็นแค่ค่าเดินทาง; สนามบินไม่มี
- [ ] คำขอยังไม่เสร็จ → ไม่มีปุ่ม
- [ ] เปิดฟอร์ม → กรอกเลขบันทึก/วันที่, เบี้ยเลี้ยง, ที่พัก, ค่าพาหนะ, ค่าอาหาร พขร. (380×1, 450×1), จำนวนหลักฐาน → ดาวน์โหลด PDF
- [ ] หน้า 1: ชื่อ พขร., วัน/เวลาออก-กลับ (เวลาจริง), รวมวัน/ชม. ถูกต้อง, ยอดรวม + ตัวอักษรไทยถูก (เช่น 2,630.50 → สองพันหกร้อยสามสิบบาทห้าสิบสตางค์)
- [ ] หน้า 2 (ส่วนที่ 2) และหน้า 3 ใบสำคัญรับเงิน: แถวค่าอาหาร พขร. และยอดรวม 830 / แปดร้อยสามสิบบาทถ้วน
- [ ] เอกสารเบี้ยเลี้ยง: ประเภท ก, จำนวนวัน, ยอดเงินถูก
- [ ] ผู้ขอ/พขร. เข้า URL ตรง → ไม่ได้
- [ ] พิมพ์จริง A4 → ตรวจตำแหน่ง
