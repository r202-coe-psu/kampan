MA 1 รายการประกอบด้วย หัวสัญญา (เลขที่ ม.อ.เบิกจ่าย ชื่อโครงการ บริษัท) และ รายการย่อย อย่างน้อย 1 รายการ แต่ละรายการย่อยมีวันเริ่ม-สิ้นสุด ยอดเงิน ผู้รับผิดชอบ และงวดจ่ายของตัวเอง ถ้าบันทึกสัญญาที่มีหลายรายการย่อย ระบบจะแยกเป็นแถวสัญญาย่อยในหน้ารายการให้ติดตามทีละรายการ

บทบาทเห็น MAเพิ่ม/แก้ไขขอต่ออายุ / ไม่ต่ออายุอนุมัติต่ออายุ
ผู้ดูแล/เจ้าหน้าที่พัสดุ (admin) ทั้งหน่วยงาน ทุกรายการ เมื่อเป็นผู้รับผิดชอบรายการนั้น ได้
หัวหน้าฝ่าย ผู้บริหาร ผู้อำนวยการ หัวหน้าฝ่ายบริหารจัดการ ทั้งหน่วยงาน เฉพาะที่ตนสร้างหรือรับผิดชอบ เมื่อเป็นผู้รับผิดชอบรายการนั้น ไม่ได้
พนักงาน (staff) และบทบาทอื่น เฉพาะที่ตนสร้างหรือเป็นผู้รับผิดชอบ เฉพาะที่ตนสร้างหรือรับผิดชอบ เมื่อเป็นผู้รับผิดชอบรายการนั้น ไม่ได้
{{ note('info', 'การขอต่ออายุ / ไม่ต่ออายุ ทำได้เฉพาะผู้ที่ถูกระบุเป็น "ผู้รับผิดชอบ" ของรายการย่อย แม้เป็น admin ก็ต้องเป็นผู้รับผิดชอบก่อน ถ้าไม่มีปุ่มขอต่ออายุ ให้ตรวจชื่อผู้รับผิดชอบในรายการนั้น') }}
{# ------------------------------------------------ 2 #}
{{ heading('list', 'ph-list-checks', '2. หน้ารายการ MA', 'เข้าจากหน้าเลือกระบบ กดการ์ด "ระบบจัดการสัญญา (MA)"') }} {% call step(1, 'เลือกมุมมองจากเมนูด้านซ้าย') %}

รายการบำรุงรักษา แสดง MA ทุกสถานะ · รอต่ออายุ สัญญาที่ผู้รับผิดชอบขอแล้ว รอ admin อนุมัติ · ต่ออายุแล้ว · ไม่ต่ออายุ

{% endcall %} {% call step(2, 'ค้นหาและกรอง') %}

ค้นหาตามชื่อหรือเลขที่ ม.อ.เบิกจ่าย กรองตามประเภท สถานะการใช้งาน (รอใช้งาน / กำลังใช้งาน / หมดอายุ) สถานะต่ออายุ และสถานะการจ่ายเงิน ถ้าหน้ารายการดูว่างเปล่า ให้ตรวจก่อนว่าตัวกรองสถานะถูกตั้งไว้หรือไม่

{% endcall %} {% call step(3, 'อ่านตาราง') %}

คอลัมน์โครงการแสดงชื่อสัญญาหลัก ส่วนคอลัมน์รายการย่อยแสดงชื่อรายการนั้น ผู้รับผิดชอบแสดงสูงสุด 2 คน ถ้ามีมากกว่านั้นกด "+N ดูทั้งหมด" เพื่อเปิดรายชื่อทั้งหมด

รายการที่แบ่งจ่ายเป็นงวดหรือมีหลายรายการย่อยจะมีปุ่มขยายแถวเพื่อดูงวดและสถานะการจ่ายแต่ละงวด ส่วนรายการจ่ายครั้งเดียวที่มีรายการย่อยเดียวจะไม่มีปุ่มนี้

{% endcall %} {% call step(4, 'ปุ่มในแต่ละแถว') %}

ดูรายละเอียด และ แก้ไข อยู่บรรทัดเดียวกัน ใต้ลงมาคือปุ่มตามสถานะ เช่น ขอต่ออายุ / ไม่ต่ออายุ (ผู้รับผิดชอบ) และ อนุมัติต่ออายุ (admin) หลังกดขอ ระบบกลับมาที่หน้ารายการเดิมพร้อมตัวกรองที่เลือกไว้

{% endcall %}

{{ heading('create', 'ph-plus-circle', '3. เพิ่มและแก้ไข MA', 'กดปุ่มเพิ่ม MA ที่หน้ารายการ หรือปุ่มแก้ไขในแถว') }} {% call step(1, 'กรอกหัวสัญญา') %}

เลขที่ ม.อ.เบิกจ่าย · วันที่เบิกจ่าย · ชื่อโครงการ · บริษัทคู่สัญญา

{% endcall %} {% call step(2, 'เพิ่มรายการย่อย (กดเพิ่มได้หลายรายการ)') %}

ชื่อรายการ · ประเภท · จำนวนและหน่วยนับ · ผังบัญชี · วันเริ่มต้น-สิ้นสุด · ยอดเงิน · หมายเหตุ

แถวย่อยของรายการ ใช้ระบุยี่ห้อ รุ่น รายละเอียด และถ้าต้องการติดตามเป็นรายชิ้นให้เปิด "ระบุ S/N" หรือ "ระบุรหัสครุภัณฑ์" ในส่วนแถวย่อย เมื่อกรอกแล้วคอลัมน์ S/N และรหัสครุภัณฑ์จะแสดงในตารางหน้ารายการด้วย

{% endcall %} {% call step(3, 'กำหนดการจ่ายเงิน') %}

เปิด "แบ่งจ่ายเป็นงวด" แล้วกรอกวันครบกำหนดและยอดของแต่ละงวด หรือปิดไว้ถ้าจ่ายครั้งเดียว ถ้ากรอกยอดเงินไม่ตรงกัน (ยอดรวมของ MA, ยอดของรายการย่อย และยอดรวมของงวด) ระบบจะแจ้งข้อความอ่านเข้าใจได้ว่าผิดที่รายการใด งวดใด แล้วให้แก้ก่อนบันทึก

{% endcall %} {% call step(4, 'เลือกผู้รับผิดชอบและฝ่ายที่มองเห็น') %}

ผู้รับผิดชอบ เลือกได้หลายคน คนเหล่านี้จะได้รับอีเมลแจ้งเตือนของรายการนั้น และเป็นคนที่ขอต่ออายุได้ ฝ่ายที่มองเห็น ใช้เลือกว่าฝ่ายไหนเห็นรายการนี้เมื่อผู้ใช้กลุ่มเห็นทั้งหน่วยงานติ๊ก "เฉพาะฝ่ายของฉัน"

{% endcall %} {% call step(5, 'ตั้งการเตือน แล้วบันทึก') %}

ดูรายละเอียดในหัวข้อ การแจ้งเตือนทางอีเมล กด บันทึก เมื่อพร้อม หรือบันทึกเป็นแบบร่างไว้กลับมาแก้ภายหลังได้

{% endcall %} {{ note('warning', 'ถ้าฟอร์มมีข้อมูลไม่ครบหรือผิด ระบบจะแสดงรายการสิ่งที่ต้องแก้ไว้ด้านบนฟอร์ม เช่น "รายการที่ 1 งวดที่ 2 วันที่: กรุณาระบุวันครบกำหนด" หลังบันทึกสำเร็จ การกดย้อนกลับของเบราว์เซอร์จะพากลับหน้ารายการ ไม่ใช่ฟอร์ม') }}
{# ------------------------------------------------ 4 #}
{{ heading('payment', 'ph-credit-card', '4. บันทึกการจ่ายเงินรายงวด', 'ใช้ได้กับผู้ที่แก้ไข MA นั้นได้') }} {% call step(1, 'เปิดหน้าการจ่ายเงิน') %}

กดที่คอลัมน์ "การจ่ายเงิน" ของรายการในหน้ารายการ หน้านี้สรุปยอดรวม ยอดที่จ่ายแล้ว และงวดทั้งหมด

{% endcall %} {% call step(2, 'บันทึกงวดที่จ่ายแล้ว') %}

กรอก วันที่จ่าย · เลขที่ ม.อ.เบิกจ่าย ของงวด · เลขที่ใบเสร็จ / ใบส่งของ (ไม่บังคับ) แล้วบันทึก สถานะของงวดและของรายการจะอัปเดตเอง

{% endcall %} {{ note('info', 'งวดที่เลยวันครบกำหนดและยังไม่ได้บันทึกจ่ายจะแสดงเป็น "เกินกำหนด" ในหน้ารายการ') }}
{# ------------------------------------------------ 5 #}
{{ heading('reminders', 'ph-bell-ringing', '5. การแจ้งเตือนทางอีเมล', 'ระบบส่งอีเมลให้ผู้รับผิดชอบของรายการนั้นอัตโนมัติ') }}
  • เมื่อถูกมอบหมาย: ผู้รับผิดชอบที่ถูกเพิ่มเข้ารายการจะได้อีเมลแจ้งทันทีที่บันทึก
  • เตือนก่อนหมดอายุ: เลือกล่วงหน้าได้ 180, 150, 120, 90, 60, 30, 15, 7 หรือ 3 วัน (ค่าเริ่มต้นคือ 90, 60, 30, 15, 7 และ 3 วัน) หรือกรอกจำนวนวันเอง
  • เตือนจ่ายงวด: เตือนในวันครบกำหนดเสมอ และเลือกเพิ่มล่วงหน้า 7, 5 หรือ 3 วันได้
  • วันที่เตือนเจาะจง: เลือกวันที่ต้องการเตือนเองจากปฏิทินได้หลายวัน
  • ระบบตรวจและส่งรอบเวลา 00:10 น. ของทุกวัน

ข้อความอีเมลแก้ได้ที่หน้า แม่แบบอีเมล ของหน่วยงาน ระบบมีแม่แบบตั้งต้นให้แล้ว ประวัติการแจ้งเตือนที่ส่งไปดูได้ที่บันทึกการแจ้งเตือนของ MA นั้น

{{ note('warning', 'ผู้รับผิดชอบต้องมีอีเมลในระบบจึงจะได้รับแจ้ง ถ้าไม่ได้รับอีเมล ให้แจ้งผู้ดูแลระบบตรวจสถานะการส่งในบันทึกการแจ้งเตือน') }}
{# ------------------------------------------------ 6 #}
{{ heading('renewal', 'ph-arrows-clockwise', '6. ขอต่ออายุและไม่ต่ออายุ', 'ผู้รับผิดชอบเป็นผู้ขอ admin เป็นผู้อนุมัติ') }} {% call step(1, 'ผู้รับผิดชอบกดขอ') %}

ที่แถวของรายการซึ่งอยู่ในสถานะ รอตรวจสอบเอกสาร กด ขอต่ออายุ หรือ ไม่ต่ออายุ รายการจะย้ายไปแท็บ รอต่ออายุ

ในแท็บรอต่ออายุ ผู้รับผิดชอบเปลี่ยนคำขอระหว่างต่ออายุกับไม่ต่ออายุได้ จนกว่า admin จะอนุมัติ

{% endcall %} {% call step(2, 'admin กดอนุมัติ') %}

กดปุ่ม อนุมัติต่ออายุ (หรืออนุมัติไม่ต่ออายุ ตามที่ผู้รับผิดชอบขอ)

  • ต่ออายุ: ระบบเปิดฟอร์มสร้าง MA ใหม่ที่คัดลอกหัวสัญญาและรายการย่อยไว้ให้ กรอกเลขที่ ม.อ.เบิกจ่าย วันเริ่ม-สิ้นสุด และงวดใหม่ แล้วบันทึก MA เดิมจะเป็น ต่ออายุแล้ว และสองรายการลิงก์ถึงกัน
  • ไม่ต่ออายุ: รายการย้ายไปแท็บ ไม่ต่ออายุ เก็บเป็นประวัติ
{% endcall %} {{ note('info', 'สัญญาหลักที่ถูกแยกเป็นสัญญาย่อยแล้วใช้อ้างอิงอย่างเดียว การขอต่ออายุให้ทำที่แถวสัญญาย่อย') }}

{{ heading('tips', 'ph-lightbulb', '7. ข้อควรรู้', 'เรื่องที่พบบ่อย') }}
ไม่เห็น MA ที่ควรเห็น

ตรวจตัวกรองสถานะที่หน้ารายการ และตรวจว่าบทบาทของคุณเห็นทั้งหน่วยงานหรือไม่ (ดูหัวข้อ 1) พนักงานทั่วไปเห็นเฉพาะรายการที่ตนสร้างหรือรับผิดชอบ

ไม่มีปุ่มขอต่ออายุ

ต้องเป็นผู้รับผิดชอบของรายการนั้น และรายการต้องอยู่ในสถานะรอตรวจสอบเอกสารหรือรอต่ออายุ แบบร่าง ต่ออายุแล้ว และไม่ต่ออายุจะไม่มีปุ่มนี้

ไม่ได้รับอีเมลแจ้งเตือน

ตรวจว่าคุณถูกเลือกเป็นผู้รับผิดชอบ มีอีเมลในระบบ และรายการนั้นตั้งช่วงเตือนไว้ตรงกับวันนี้
