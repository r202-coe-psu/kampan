ขั้นตอนการใช้งาน

  1. 1. เปิดเมนู “รถยนต์”

    ระบบแสดงรายการรถทั้งหมดของหน่วยงาน พร้อมรูปรถ ป้ายทะเบียน เลขไมล์ล่าสุด และสถานะ

  2. 2. กด “เพิ่มรถยนต์”

    กรอก ป้ายทะเบียน (บังคับ), เลขไมล์ล่าสุด, คำอธิบายรถ, สถานะการใช้งาน และอัปโหลดรูปรถ

  3. 3. บันทึก

    รถคันนี้จะไปปรากฏเป็นตัวเลือกในหน้า “พัสดุอนุมัติขอใช้รถยนต์” และในฟอร์มขอใช้รถทันที

  4. 4. ปุ่ม QR Code (ถ้าต้องการ)

    ดาวน์โหลดรูป QR ของรถคันนั้นเป็นไฟล์ PNG สำหรับพิมพ์ติดในรถ ให้ผู้โดยสารสแกนเพื่อทำแบบประเมิน

  5. 5. แก้ไข / ลบ

    การลบเป็นการเปลี่ยนสถานะเป็น “ไม่สามารถใช้งานได้” ไม่ได้ลบข้อมูลจริง ประวัติการใช้รถคันนั้นในอดีตจะยังอยู่ครบ

ขั้นตอนการใช้งาน

  1. 1. กด “สร้างแบบประเมิน”

    ตั้งชื่อแบบประเมิน ใส่คำอธิบาย และเลือกรถที่จะใช้แบบประเมินชุดนี้ (เลือกได้หลายคัน)

  2. 2. เพิ่มคำถาม
    เลือกชนิดคำถามได้ 5 แบบ และกำหนดได้ว่าข้อไหนบังคับตอบ
    ให้คะแนน 1–5 ข้อความ ใช่ / ไม่ใช่ เลือกตอบข้อเดียว เลือกตอบหลายข้อ
  3. 3. บันทึก แล้วกดปุ่ม QR Code

    ระบบสร้าง QR ต่อรถ 1 คัน เมื่อสแกนจะเปิดหน้าแบบประเมินของรถคันนั้นโดยตรง ผู้ตอบไม่ต้องเข้าสู่ระบบ

  4. 4. ดูผลสรุป

    ระบบสรุปให้อัตโนมัติ: คำถามแบบคะแนนแสดงค่าเฉลี่ยและการกระจายคะแนน 1–5, คำถามแบบตัวเลือกแสดงจำนวนครั้งที่แต่ละตัวเลือกถูกเลือก, คำถามแบบข้อความแสดงรายการคำตอบทั้งหมด และกรองดูเฉพาะรถคันใดคันหนึ่งได้

  • พัสดุ (admin) และหัวหน้าฝ่ายบริหารจัดการ — เห็น คำขอทั้งหมดของหน่วยงาน
  • รายการเรียงจากคำขอที่สร้างล่าสุดขึ้นก่อน

ขั้นตอนสร้างคำขอ

  1. 1. กด “เพิ่มคำขอใช้รถยนต์”
  2. 2. เลือกประเภทการใช้รถ — ตัวเลือกนี้กำหนดเส้นทางการอนุมัติ
    ประเภทการใช้รถ ฟิลด์ที่ต้องกรอกเพิ่ม ส่งเข้าขั้นอนุมัติ
    ใช้รถทั่วไป – รอหัวหน้าฝ่ายอนุมัติ
    รับส่งสนามบิน เลือก รับ หรือ ส่ง, สถานที่รับผู้โดยสาร, หมายเลขเที่ยวบิน, เวลาเครื่องออกจาก/มาถึงสนามบินหาดใหญ่ รอหัวหน้าฝ่ายอนุมัติ
    ไปต่างจังหวัด – รอพัสดุเสนอ ผอ.
  3. 3. เลือกประเภทการเดินทาง

    ไป-กลับ ต้องกรอกวัน-เวลากลับด้วย / เที่ยวเดียว กรอกเฉพาะวัน-เวลาออกเดินทาง (ช่องวันกลับจะถูกซ่อนให้เอง)

  4. 4. กรอกรายละเอียดการเดินทาง

    เหตุผลที่ต้องการใช้, สถานที่ต้องการจะไป, จำนวนผู้โดยสาร, เบอร์โทรศัพท์ผู้ขอใช้รถ, วัน-เวลาออกเดินทาง (และวัน-เวลากลับ)

  5. 5. รถยนต์ / พนักงานขับรถ (ไม่บังคับ)

    เว้นเป็น “ไม่ได้ระบุ” ได้ ปกติพัสดุจะเป็นผู้จ่ายรถและพนักงานขับรถให้ในขั้นอนุมัติสุดท้าย การเลือกไว้ถือเป็นการแจ้งความประสงค์เท่านั้น

  6. 6. บันทึก

    ระบบบันทึกฝ่าย (division) ของผู้ขอไว้กับคำขอโดยอัตโนมัติ (ใช้ในการกรองของหัวหน้าฝ่าย) และส่งอีเมลแจ้งผู้อนุมัติขั้นถัดไปทันที

  1. 1. เลือกคำขอที่ผ่านการอนุมัติต้นทางมาแล้ว

    คำขออาจมาจากหัวหน้าฝ่าย (ใช้รถทั่วไป / รับส่งสนามบิน) หรือจาก ผอ. (ไปต่างจังหวัด)

  2. 2. เช็กว่าวันเวลานั้นรถว่างจริง

    แนะนำเปิดเมนูปฏิทินการขอใช้รถยนต์ประกอบ เพื่อไม่ให้จ่ายรถคันเดียวกันซ้อนกัน

  3. 3. เลือกรถยนต์และพนักงานขับรถในแบบฟอร์มอนุมัติ

    ตัวเลือกรถมาจากเมนู “รถยนต์” และตัวเลือกคนขับมาจากผู้ใช้ที่มีบทบาท พนักงานขับรถ (driver) ในหน่วยงานนี้

  4. 4. กด “อนุมัติ”
    จะเกิด 3 อย่างพร้อมกัน:
    • สถานะเปลี่ยนเป็น อนุมัติสำเร็จ
    • คำขอไปปรากฏใน “รายการงาน” ของพนักงานขับรถที่ถูกจ่ายงาน
    • ระบบส่งอีเมลแจ้งพนักงานขับรถทันที
  5. 5. หรือกด “ไม่อนุมัติ”

    การ์ดงานแสดงวัน-เวลาออกเดินทาง ประเภทการใช้รถ ป้ายทะเบียนรถ ผู้ขอใช้ เหตุผล และรายละเอียดเที่ยวบินหากเป็นงานรับส่งสนามบิน

  3. 3. เมื่อกลับถึงที่แล้ว กดปิดงาน

    กรอก เลขไมล์หลังกลับ จากหน้าปัดรถ แล้วยืนยัน

  4. 4. ระบบบันทึกให้อัตโนมัติ
    • เก็บเลขไมล์เดิมของรถไว้เป็น “เลขไมล์ก่อนออกเดินทาง”
    • อัปเดตเลขไมล์ล่าสุดของรถคันนั้นเป็นค่าที่กรอก
    • บันทึกวันเวลากลับเป็นเวลาที่กดปิดงาน
    • เปลี่ยนสถานะเป็น เสร็จสิ้น งานจะหายจากรายการงานและไปอยู่ในประวัติการใช้รถยนต์
