ขั้นตอนการใช้งาน

  1. 1. เปิดเมนู “รถจักรยานยนต์”

    ระบบแสดงรายการรถทั้งหมดของหน่วยงาน พร้อมรูป ป้ายทะเบียน เลขไมล์ และสถานะ

  2. 2. กดเพิ่มรถ แล้วกรอกข้อมูล

    ป้ายทะเบียนรถ (บังคับ), รายละเอียด/ลักษณะ, เลขไมล์สุดท้าย (บังคับ) และอัปโหลดรูปรถ (png / jpg / jpeg)

  3. 3. บันทึก

    รถคันนี้จะไปปรากฏเป็นตัวเลือกในช่อง “รถมอเตอร์ไซค์” ของฟอร์มขอใช้รถทันที

  4. 4. แก้ไข / ลบ

    การลบเป็นการเปลี่ยนสถานะเป็น “ไม่สามารถใช้งานได้” ไม่ได้ลบข้อมูลจริง คำขอในอดีตที่อ้างถึงรถคันนั้นจะยังอยู่ครบ

สิ่งที่เห็นในหน้ารายการ

  • พนักงานทั่วไป — เห็นเฉพาะคำขอที่ ตนเองเป็นผู้สร้าง
  • พัสดุ (admin) และหัวหน้าฝ่ายบริหารจัดการ — เห็น คำขอทั้งหมดของหน่วยงาน
  • รายการเรียงจากคำขอที่สร้างล่าสุดขึ้นก่อน

  2. 2. กรอกข้อมูล 5 ช่อง

  3. 3. บันทึก

    ระบบขึ้นหน้าต่าง “การดำเนินการเสร็จสิ้น” พร้อมส่งอีเมลแจ้งพัสดุ และคำขอเข้าสถานะ รอการอนุมัติ

ขั้นตอนการใช้งาน

  1. 1. เปิดปฏิทิน แล้วเลื่อนดูเดือนที่ต้องการ

    แต่ละรายการแสดงเป็นช่วง 1 วันตามวันออกเดินทาง

  2. 2. คลิกที่รายการในปฏิทิน

    ดูรายละเอียดย่อ ได้แก่ ป้ายทะเบียน เหตุผล และสถานที่ที่ต้องการจะไป
